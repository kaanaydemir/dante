# Source texts

Henry Wadsworth Longfellow's English translation of the *Divine Comedy* (1867) is in the public domain.
This is the only translation the project quotes from verbatim.

- `longfellow-{inferno,purgatorio,paradiso}.txt`: the original Project Gutenberg e-texts (#1001, #1002, #1003) with their license headers, mirrored from the GITenberg project.
- `{inferno,purgatorio,paradiso}/canto-NN.txt`: the same verse split into one file per canto, with every verse line numbered (`<line> | <verse>`).

Use these numbered files when quoting in scripts and Codex entries: cite as `Inferno V, 121–123`.
Inferno line totals match the Italian original exactly (4720 lines), so Longfellow line numbers can stand in for the Italian ones.
