# Divine Comedy — The Descent

A browser-based 2D action-adventure game inspired by Dante Alighieri's *Divine Comedy*.
The player guides Dante, with Virgil at his side, down through the nine circles of Hell, up Mount Purgatory and into Paradise. Each circle's punishment (its *contrapasso*) becomes a gameplay mechanic.

**Status:** design phase. See the [Game Design Document](docs/GDD.md) (in Turkish).

Planned stack: Phaser 3 · TypeScript · Vite · Tiled · GitHub Pages.
